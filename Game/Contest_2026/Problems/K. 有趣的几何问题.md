给定一个正整数参数 $r$，求满足下列所有条件的 $n$ 个不相同有序数对 $(x, y)$：  
​  
- $x^2 + y^2 = r^2$；
- $x$，$y$ 均为有理数；
- $0 \leq x \leq y$。

对于两个数对 $(x_1, y_1)$ 和 $(x_2, y_2)$，它们相同当且仅当 $x_1=x_2$ 且 $y_1=y_2$。  
  
数据保证对于任意给定的 $r$，$n$，均存在至少 $n$ 组满足条件的数对。  
  
本题开启特殊测评，你可以按任意顺序输出。


## 输入
仅有的一行输入包含两个正整数 $r$，$n$ ，分别表示参数的值、要求的数对个数。
$(1\le r\le 100,\ 1\le n\le 10^5)$
## 输出

输出 $n$ 行，每行包含两个有理数，分别表示 $x$ 和 $y$。  
  
每个有理数均以最简分数 $\texttt{p/q}$ 的形式输出，其中：  
  

- $p$ 为分子，$q$ 为分母；
- $p$，$q$ 均为整数，且 $q > 0$；
- $\gcd(|p|, q)=1$，即不可继续约分；
- 若该数为整数 $k$，则输出 $\texttt{k/1}$。

  
本题中还额外要求 $|p|, q \leq 10^9$。
## 样例输入
```
5 3
```

## 样例输出
```
0/1 5/1
3/1 4/1
25/13 60/13
```
