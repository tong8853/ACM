## A. 南瓜校园骑

南瓜大学的体育课要求每个学期跑 $60$ 公里的校园跑，限制每天的跑量不会超过 $2$ 公里，跑步速度不能慢过 $10$ 分钟每公里，而且必须要绕操场一圈（$400$ 米）经过必经点位才行。校园跑的本意是好的，但却也促进了校园骑的发展。

小盼是南瓜大学的一名学生，每天她会先进行校园骑，已知她现在已经骑行了 $x$ 公里，平均速度为 $y$ 分钟每公里；而她校园跑的平均速度为 $z$ 分钟每公里；行程超过 $2$ 公里且绕操场至少一圈后，小盼便立即停止，无论速度是否达标。

请你写一个程序快速判断小盼是否能在规定速度内完成任务，只需要输出她整个过程的平均速度即可。

注意：
速度单位是分钟每公里，不是常用的公里每小时！
不能在操场上骑行；
校园骑一结束立刻在操场进行校园跑。


## 输入

一行三个小数，分别表示校园骑的行程和速度，以及校园跑的速度。

## 输出

输出一个整数，表示她整个过程的速度（单位是分钟每公里），舍去小数位，只输出整数部分。


## 样例输入
```
1.2 2 5
```


## 样例输出

```
3
```
