在一个一位坐标轴上，分布这 $n$ 个能量球，每个球的坐标给定为 $a_i$。  
  
受到神秘力量的影响，每个能量球会同时以每秒 $1$ 单位的速度，匀速向着各自的目标 $b_i$ 前进；一旦到达目标地，便停止运动。  
  
当某一个时间两个能量球在一个地点相遇，会产生一次能量碰撞，爆发出 1 点能量值，但这并不会影响能量球的运动。注意一个已停止运动的球也会触发能量碰撞。  
  
小球初始的位置和目标地的坐标均互不相同。  
  
求这个过程会产生多少能量值？

## 输入
第一行一个正整数 $T (1\le T\le 10^3)$表示数据组数。  
  
每组数据的第一行为一个正整数 $n (1\le n\le 10^5)$ 表示能量球数量。  
  
之后 $n$ 行，第 $i$ 行为一对整数 $a_i, b_i$，表示第 $i$ 个球的初始位置和终点。  
  
$-10^9\le a_i, b_i\le 10^9$，保证这 $2n$ 个数互不相同。  
  
所有测试数据的 $n$ 的总和不超过 $2\times 10^5$。

## 输出

对每组数据输出一个整数，表示这整个过程会产生的能量值。
## 样例输入
```
2
2
1 3
4 2
3
1 3
0 2
-1 4
```

## 样例输出
```
1
2
```
