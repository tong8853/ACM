可莉的探险队在阿努比斯深渊中找到了一头奶黄色的恐龙，形状奇特，性格温顺，叫声为人类大笑声，是危机四伏的深渊中罕见的和平生物。通过格雷科技，可莉解析出了这头恐龙的生物遗传密码，并通过射线方式将密码向上发射，希望地面上的人们能够破解其中的秘密。  
​  
射线所含的信息为一串很长的十进制数字 $x$，首位不为 $0$。在发射前可莉可以进行任意次如下修改操作：  
  
选择一位数字，如果它的平方不大于 9，则可以选择将它替换为它的平方。  
  
比如数字 $25$，可以将 $2$ 替换成 $4$，变成 $45$。但不能选择 $5$。  
  
由于阿努比斯深渊拥有特殊磁场，会干扰射线，但如果射线所表示的数字能被 $9$ 整除，磁场就难以对射线造成干扰，否则射线将发射失败。  
  
请你判断可莉是否能通过上述操作成功发射射线，从而帮助人类进一步了解深渊中的秘密。
## 输入
第一行一个整数 $T\ (1\le T\le 10^3)$ 表示数组组数。  
  
每组数据包含一行，为该数字本身 $x$。其长度设为 $n$，则 $1\le n\le 10^5$。

## 输出

对每组数据输出判断，能成功完成则输出 YES，否则 NO。
## 样例输入
```
3
114514
333
1234567890
```

## 样例输出
```
NO
YES
YES
```
