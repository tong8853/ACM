## B. 网址模拟器
从模拟动物，模拟仙人掌，到模拟装机，模拟厕所，模拟器模拟万物。于是我们今天来模拟一下网址。

网址模拟器支持以下功能或操作：
- 维护一个历史记录和前进记录列表，均拥有最大容量 $cap$。每次访问新地址会清空前进记录。如果容量溢出，则删除列表中最早加入的记录。
- 初始时当前地址为 home，历史和前进记录均为空。
- home： 若当前不为 home，则将当前地址加入历史记录，跳转到主界面，清空前进记录；否则，不做任何操作。
- visit url： 如果访问的地址与当前地址不同，将当前地址加入历史记录，访问 url 地址，清空前进记录；否则，不做任何操作。
- forward：将当前地址加入到历史记录中, 切换到下一页，如果前进记录为空，不做操作。
- return：若历史记录不为空，则将当前记录添加到前进记录列表中，访问历史记录中的上一个网址；如果历史记录为空，不做操作。
- now：输出当前页面地址。
- close: 关闭浏览器，结束程序。

如果历史记录中出现相同的地址，保留。
若给出的指令不符合上述任何操作，则不做任何行动，转到下一条指令。
地址 url 均由字母，数字或 "." 符号构成，不会有别的字符。

## 输入

第一行一个整数 $cap (1\le cap\le 10)$，表示两个记录列表的最大容量。
之后若干行，每行一个操作。保证必有一个 now 操作，且以 close 操作输入结尾。
指令数量不超过 $10^3$，地址字符串长度不超过 $100$。

## 输出

对每个 now 操作输出一行表示当前地址。

## 样例输入

```
2
visit baidu.com
now
visit google.com
now
return
now
forward
now
home
now
close
```

## 样例输出

```
baidu.com
google.com
baidu.com
google.com
home
```
