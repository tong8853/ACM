奶茶批发商小红有 $n$ 杯奶茶和 $m$ 个朋友，现在她想将所有的奶茶都分发给朋友们，当然自己也要分到。善良的小红不希望有人少分或多分了，也就是说她希望所有人分得的奶茶数量是相等的，且每个人至少分得一杯奶茶。她可以去商店购买奶茶，购买数量没有限制，但数量尽量少，毕竟小红没有多少压岁钱了。

请问小红最少需要购买多少杯奶茶？


## 输入
第一行一个整数 $T (1\le T\le 100)$，表示数据组数。  
  
每组数据共一行两个整数 $n (0\le n\le 10^{12})$ 和 $m (0\le m\le 10^{12})$，分别表示已经拥有的奶茶数量和朋友数量。

## 输出
每组数据输出一行一个整数，表示最少购买奶茶数量。

## 样例输入
```
2
1 1
4 3
```

## 样例输出
```
1
0
```

## 提示
已有 $1$ 个奶茶，$1$ 个朋友，则还最少需要买 $1$ 个奶茶（别把小红漏了）。
