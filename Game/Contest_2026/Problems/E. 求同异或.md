小童有一个长度为 $n$ 的数组，每次他可以选择两个相邻的数字，将它两移除，并在相同的位置插入它两的异或值。  
  
请问小童是否能得到一个元素均相等的数组? 注意最终数组长度需要不小于 $2$。  
  
比如初始数组是 $a=[0, 2, 2]$，可以选择 $a_0$ 和 $a_1$ 进行异或，$a_0\oplus a_1=0\oplus 2=2$，将 $a_0, a_1$ 删除，原地插入结果 $2$，得到 $[2,2]$， 此时数组元素均相等，且长度不小于 $2$。

## 输入

第一行一个整数 $T\ (1\le T\le 30)$，表示数据组数。  
​  
每组数据第一行一个整数 $n\ (2\le n\le 1000)$，表示数组长度。  
  
第二行 $n$ 个数 $a_i\ (0\le a_i\lt 2^{30})$，表示数组各个元素的值。
## 输出
每组数据输出一行，如果能获得元素均相等的数组则输出 YES, 否则 NO。

## 样例输入
```
3
2
1 1
3
2 0 2
4
4 3 2 1
```

## 样例输出
```
YES
YES
NO
```
